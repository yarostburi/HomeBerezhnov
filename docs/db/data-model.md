# Модель данных

## Клиент

Реестр клиентов.

| Название | Тип | Описание |
| -------- | --- | -------- |
| id | smallint | Идентификатор клиента (PK) |
| name | varchar(50) | Полное имя |
| mail | varchar(50) | Адрес электронной почты |
| phone | varchar(50) | Контактный телефон |
| address | varchar(50) | Физический адрес |


## Заявка

Зарегистрированные заявки.

| Название | Тип | Описание |
| -------- | --- | -------- |
| id | smallint | Идентификатор заявки (PK) |
| Клиент_id | smallint | Ссылка на Клиента (FK) |
| date_start | timestamp | Дата и время начала работ |
| date_finish | timestamp | Дата и время окончания работ |
| price | varchar(20) | Стоимость работ по заявке |


## Объект

Объект принадлежащий заявке.

| Название | Тип | Описание |
| -------- | --- | -------- |
| id | smallint | Идентификатор объекта (PK) |
| code | varchar(100) | Уникальный код объекта (UNIQUE) |


## Отчет

Отчет составленый ответственым и принадлежащий объекту.

| Название | Тип | Описание |
| -------- | --- | -------- |
| id | smallint | Идентификатор ответственного (PK) |
| name | varchar(50) | Полное имя |
| mail | varchar(50) | Адрес электронной почты |
| phone | varchar(50) | Рабочий телефон |
| post | varchar(50) | Должность |

## Ответственный

Человек создающий отчет.

| Название | Тип | Описание |
| -------- | --- | -------- |
| id | smallint | Идентификатор объекта (PK) |
| code | varchar(100) | Уникальный код объекта (UNIQUE) |
| Ответственный_id | smallint | Ссылка на Ответственного (FK) |
| Объект_id | smallint | Ссылка на Объект (FK) |
